Senha de administração

Esta página cria acessos ao sistema. A senha fica apenas nesta aba do navegador e é esquecida ao fechá-la.

Marque gerações por conta do servidor para quem você não quer obrigar a criar uma chave de API — os convidados de um teste, tipicamente. Cada convite marcado tem uma cota; os demais informam a própria chave no navegador.

O banco de questões é derivado do nome, não do código. Reemitir um convite para alguém com o nome escrito igual devolve o acervo dela; escrito diferente, cria um acervo novo e vazio.
